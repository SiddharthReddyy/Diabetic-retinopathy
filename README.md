# Diabetic Retinopathy Detection

Deep learning model that classifies diabetic retinopathy (DR) severity from retinal fundus images. Diabetic retinopathy is a diabetes complication that affects the eyes and can lead to blindness if not detected early.

## Objectives
- Detect and classify stages of diabetic retinopathy from retinal images
- Build a reliable and accurate deep learning model
- Reduce manual effort in medical diagnosis
- Provide a scalable solution for screening systems

## Classes
The model takes a retinal image as input and classifies it into one of five categories:
- 0: No DR
- 1: Mild
- 2: Moderate
- 3: Severe
- 4: Proliferative DR

## Files
- `Dr.ipynb`, `image_classification.ipynb`: model development
- `app.py`: application code
- `dataset1/`, `Test/`: data
