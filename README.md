# Diabetic-retinopathy
Mini project

This project focuses on building a deep learning model to automatically classify Diabetic Retinopathy (DR) from retinal fundus images. Diabetic Retinopathy is a diabetes complication that affects the eyes and can lead to blindness if not detected early.

#Objectives
Detect and classify stages of diabetic retinopathy from retinal images
Build a reliable and accurate deep learning model
Reduce manual effort in medical diagnosis
Provide a scalable solution for screening systems

Classes

The model classifies images into the following categories:

0: No DR
1: Mild
2: Moderate
3: Severe
4: Proliferative DR
